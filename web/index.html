Using the console

      
The dark screen is a terminal connected to the emulated computer's serial port. Click it and type, or use Try these for ready-made commands.

      
Keyboard shortcuts

      
These work when the terminal isn't focused. Click anywhere on the panel first.

      

        
SpaceHalt or resume the CPU

        
SRun one instruction, then halt

        
BGo back one instruction

        
Shift+BGo back to just before the last trap

Words on the panel

      

        
Register
One of the CPU's 32 small storage slots. Every calculation reads from and writes to them.

        
Program counter
The address of the next instruction to run.

        
Privilege mode
Machine (firmware), Supervisor (operating-system kernel) or User (normal programs). Programs can't touch hardware directly; they ask the kernel.

        
System call
A program asking the kernel to do something for it, like read a file or print text. The CPU jumps from U to S mode to handle it.

        
Trap
Any jump into the kernel: system calls, timer ticks, key presses, disk activity, or errors.

        
Interrupt
A trap caused by hardware rather than the running program, like the timer or the keyboard.

        
CSR
Control and status register: settings the kernel uses to steer the CPU.

        
WFI
"Wait for interrupt". The kernel has nothing to do and pauses the CPU until something happens.

      

      

    

  

  
    
About this machine

    

      
rvwasm

      
A RISC-V computer emulated in your browser. The CPU is written in Rust and compiled to WebAssembly; nothing runs on a server.

      
What's emulated

      
    
        
  • Time travel: the machine can run backwards, one instruction at a time, because every run is exactly repeatable.
    • 
        
  • A 64-bit RISC-V processor, RV64GC (RV64IMAFDC with Zicsr and Zifencei): integer maths, multiply/divide, atomics, single and double precision floating point, 16-bit compressed instructions and control registers. That is the instruction set standard RISC-V Linux software is built for. On top of that it has the bit-manipulation extensions (Zba, Zbb, Zbc, Zbs) and Zicond, which Linux uses for its string routines.
    • 
        
  • Machine, Supervisor and User privilege modes, traps and interrupts.
    • 
        
  • Sv39 virtual memory with a software TLB.
    • 
        
  • A 16550 serial port (the terminal), CLINT timer, PLIC interrupt controller and a virtio block disk.
    • 
      

      
What it runs

      
xv6 is MIT's small teaching version of Unix. Linux 6.12 boots with BusyBox, a compact set of standard Unix commands. Both are built from source for this CPU.

      
It passes all 334 official riscv-tests for its instruction set, and xv6's own test suite.
